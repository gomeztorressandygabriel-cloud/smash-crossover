# Smash Crossover

Super Smash Bros. 64 y Super Smash Bros. Melee en la misma partida.

## Instalar

1. Descarga `SmashCrossover-<version>.zip` del [último release](../../releases/latest) y descomprímelo.
2. Abre `SmashCrossover.exe`.
3. Elige **tu** ROM de Super Smash Bros. (N64, USA) y **tu** ISO de Super Smash Bros. Melee (GameCube NTSC 1.02).
   Los juegos no vienen incluidos: el instalador prepara todo con los tuyos.
4. Pulsa **INSTALAR** y luego **JUGAR**.

Cada vez que abras `SmashCrossover.exe` buscará actualizaciones y bajará solo lo que cambió.
